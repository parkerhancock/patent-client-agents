USPTO Alert

New Office Action APIs, site improvements, and more

Our team continues to deliver improvements incorporating your feedback. The latest Open Data Portal (ODP) release includes the following:

  • Legacy Office Action APIs from Developer Hub are now in ODP. See the APIs page for more details.
  • The Trademark Status & Document Retrieval Swagger UI is also now in ODP. To learn more about using this Swagger UI, check out our video tutorials.

We also added a Data Dissemination section to the home page to help you navigate ODP's rich datasets and information. Finally, an updated Release Notes page now has the latest product news right at the top.

If you have any questions or need support, email us at data@uspto.gov. We appreciate all of your feedback.
