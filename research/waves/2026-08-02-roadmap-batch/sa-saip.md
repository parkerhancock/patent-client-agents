# SAIP reconciliation note

**Entity:** `SA/SAIP`  
**Verified:** 2026-08-02  
**Verdict:** `red_no_api`

SAIP now publishes a modern public website, a service directory, fee-bearing
service pages, an IP gazette, open-data navigation, and an IP Search Engine
landing page. This corrects the May synopsis's broad claim that the main site
was wholly unavailable from outside Saudi Arabia.

The search application at `ipsearch.saip.gov.sa` still timed out from direct
US egress during this check. SAIP publishes no supported search API or bulk
register. The official trademark registration page does publish current fees,
so manual fee research no longer depends only on older WIPO Lex regulations.

The register connector remains red. Recheck the search host and open-data area
quarterly. A documented API or downloadable record feed would justify a new
review.
