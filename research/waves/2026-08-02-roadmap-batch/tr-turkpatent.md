# TÜRKPATENT reconciliation note

**Entity:** `TR/TURKPATENT`  
**Verified:** 2026-08-02  
**Verdict:** `green` for fees; no supported register API

The existing synopsis already documents official server-rendered fee tables
for patents, utility models, trademarks, and designs. Those tables remain the
best next connector target.

TÜRKPATENT also provides public browser search for patents, trademarks, and
designs. The patent guide documents file tracking, detailed search, advanced
search, and document access. The office publishes no API or bulk-data contract
for these search applications. Higher-layer patent and international-register
coverage is sufficient until a supported national interface appears.
